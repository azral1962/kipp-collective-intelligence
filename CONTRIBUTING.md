# Contributing

1. Find an Issue or propose one with a user need and acceptance criteria.
2. Fork or create a branch named `Txx/short-task`.
3. Copy the appropriate file from `templates/`.
4. Use only shareable/synthetic material; include sources.
5. Add an example, tests/evaluation evidence, status and author/reviewer handles.
6. Open a PR against `main`; request review from another team.
7. Address feedback. Maintainer merges after checks pass.

Never submit passwords, API tokens, private student transcripts, exam questions, or unlicensed copyrighted files.
