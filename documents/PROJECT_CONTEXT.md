# Project context / handoff to desktop Codex

## Purpose
A three-week capstone pilot for 60+ students in Interpersonal & Public Communication (KIPP), designed to form a student learning community whose methods carry into other courses.

## Educational rationale (TAIDA)
- Target: change individual learning into verified collaborative learning.
- Attention: academic challenges often recur while peer knowledge stays scattered.
- Interest: everyone can contribute, reuse and improve accessible academic techniques.
- Desire: a practical commons of tested prompts, skills, cases and workflows.
- Action: 10 teams deliver a working MVP and handover in three weeks.

## Core libraries
- Prompt patterns: 5 each for Study, Research, Design, Implementation, Paper (25 proposed).
- Skills: Python/simulation, scientific visualization, tables/spreadsheets, presentations, educational videos, scientific documents (15 proposed).
- Collective memory: structured concepts, problems, methods, results, sources, and reflections.
- Community workflow: ask → listen → share → review → verify → improve.

## Optional Telegram AI Forum Facilitator
- Passive observation of **authorized** group messages only if explicit group policy/permissions are in place.
- Reply on-demand (`/ask`, `/find`, `/summary`), not unsolicited interventions.
- Locate and cite trusted catalogue records. Draft suggestions require human curation before publication.
- Target local inference through Ollama; one server can host multiple logical agents.

## Agreed minimum at week three
10 tested prompts; 6 tested skills across six categories; one catalogue; one end-to-end demonstration; individual portfolios; sustainability/handover.

## Scope constraints
No compulsory multi-agent platform, proprietary paid accounts, native mobile app, or production-grade monitoring system. First preserve educational utility and privacy.

## Not decided (must confirm with humans)
Course cohort names, exact class dates, GitHub organization, grade policy, host machine deployment, permitted Telegram group and retention terms.
