# PY-03 — Python Numerical Simulation

## Inputs
Question; assumptions; model; parameters; expected output.

## Procedure
1. Confirm mathematical model and assumptions.
2. State expected limiting or analytical result, if available.
3. Write a reproducible Python script with a fixed seed.
4. Run locally and check a known case.
5. Save parameters and evidence.
6. Explain limits, numerical uncertainty and reproducibility.

## Acceptance
Program executes and tests pass; outputs are described honestly and can be reproduced. Current example is a draft.
